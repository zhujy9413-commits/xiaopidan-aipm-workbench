# HTML 交付规范

默认生成一个 UTF-8 独立 HTML 文件，适合本地浏览与评审。只做报告文件，不扩展为网站、账号系统或在线发布项目。用户另有明确格式要求时遵从，不强制 HTML。

## 信息与交互

- 设置中文标题、语言、viewport、报告日期和状态。日期使用用户时区。
- 顶部提供一页决策摘要，突出结论、目标、范围、投入状态、关键条件与待拍板事项。
- 使用语义化标题和稳定锚点，导航链接覆盖实际章节。桌面可采用侧栏，窄屏可收起或改为顶部目录；导航不得遮挡正文。
- 以表格呈现必要对比。小屏表格可横向滚动，正文保持可读。
- 附录用原生 details/summary 或同等可访问方式展开；核心风险、条件与决策不能只藏在附录。
- 来源链接在相关结论附近，附录可提供完整来源与口径。内部材料标明名称和日期即可，不曝光私人本地路径、访问凭据或无法授权分享的链接。
- 事实、假设、缺口和待决策状态用文字标明，不能只靠颜色区分。

## 视觉与可携带性

以清晰阅读为先，布局与配色按项目适当调整。保留案例的一页结论、导航、表格和可展开附录，不复制业务内容或逐像素套版。不要求封面、插画或动画。

CSS 与必要的 JavaScript 内嵌，优先系统字体和原生交互，避免 CDN、外部字体、追踪或联网才能显示的组件。如需图形，优先内嵌 SVG 并提供文字解释。用户内容写入 HTML 时进行转义，不能把原始材料中的脚本当成报告代码。

加入打印样式：隐藏交互导航、展开附录内容、减少断页损坏和截断。报告不应依赖悬浮提示才能理解核心内容。

## 验证与交付

先核查确认稿与 HTML 中的数字、范围、结论、条件和来源一致，检查锚点唯一且存在、链接可用以及没有占位符。

使用当前可用浏览器查看真实页面，验证桌面、窄屏、导航、附录展开和打印布局。若工具不支持本地文件，可在报告目录启动只监听本机的临时服务进行预览，用完关闭。浏览器或打印检查不可用时完成可行的静态检查并明确未验证项，不声称已完成视觉检查。

保存到用户指定位置或当前工作目录，提供绝对路径链接。可用且有帮助时在 Codex 中打开报告供用户查看。创建报告不代表同意上传、发布或发送给他人。
