# 交付与验收

只读取当前请求所需的交付方式。以一份维护源保存正文，文件和云端版本都从它更新；工作底稿不等于已交付成果。

## HTML

- 默认生成可独立打开的 UTF-8 中文 HTML，包含文档标题、开篇定义与状态、九节正文及表格。目录只提供导航，不重复正文；用户有另定结构时同步目录。
- 使用语义化标题、清楚的表头、稳定的文字对比和适合中文的字体。宽表在窄屏可横向滚动，长文本能换行；打印时隐藏导航并合理处理表头和分页。
- 正文与样式尽量自包含，不要求联网才能读。不把数据文件、个人答卷或内部临时路径嵌入成品。
- 实际打开或渲染检查开篇、正文中部、最后一节和最宽表格。检查桌面可读性，交付预期涉及手机或打印时再检查相应视图；修复空白、裁切、重叠和标题错位。

## 飞书或其他云文档

写入前确认用户指定的准确目标、是否新建或更新，以及现有内容是否属于本次范围。用户已明确要求写入该文档且权限可用时直接执行；登录或工具切换不构成再次询问的理由。无权访问时保留已完成文件，说明具体缺口，不绕过权限。

优先使用实际可用的文档连接器；没有合适接口时使用环境允许的浏览器方式。不要写死某个插件、浏览器、私有接口、选择器或坐标；先读取当前状态。

富文本写入需检查以下易错处：

- 仅写入正文；HTML 目录、侧栏、页脚和重复标题不要粘进正文。
- 编辑器的“全选”可能只选中当前引用块或表格。替换正文前核对选区范围，优先定位明确的文档块；不要以按过快捷键为依据覆盖内容。
- HTML 表格可能转成嵌入表格或电子表格，原 CSS 列宽未必保留。逐个检查单元格内容、换行、宽度及页面溢出，使用目标应用支持的格式设置修复。
- 未知写入结果先检查云端状态，再决定是否重试，避免重复章节。工具失败后需要新的诊断依据，不盲目重复同一动作。
- 等待保存完成，并通过重新打开或刷新复核标题、开篇、中段表格和末尾章节。不能仅凭“粘贴成功”或本地正文正确就认定云端交付完成。

## 最终检查

结构按九节模板及用户修改核对；产品名、年龄或其他人群设定、角色称呼和场景范围要一致。检查关键数字与分母、原话定位、数据用途，以及第九节的“已完整读取”是否属实。

删除空白占位、模板提示和工作过程文字。修改后同步约定交付版本，不额外扩展到未请求的格式或发布渠道。最终回复给可打开的文件或文档链接，准确说明已生成、已写入或仍受阻的状态。
