# 方法与证据标准

## 按阶段选择重点

| 阶段 | 首要问题 | 产出重点 |
| --- | --- | --- |
| 想法 | 哪类人可能存在什么未满足问题？ | 候选群体、替代方案、假设画像与最小验证安排 |
| 立项 | 谁的问题值得优先解决，依据是否充分？ | 核心群体、问题强度、反例、可触达性与证据缺口 |
| MVP | 第一版服务谁、支持哪个关键场景？ | 场景触发、最小成功结果、使用约束、首批验证对象 |
| 上线迭代 | 实际使用差异是否改变原画像？ | 行为反馈、生命周期、留存与流失原因、画像更新 |

按目标选择深度，不强制执行完整调研；有充分材料时先综合，不从零询问。

## 证据与推理

对核心判断维护简洁记录：编号、判断、证据类型、来源或材料定位、适用人群与时间、局限、待验证动作。重复来源可合并，不为每句话创建庞大台账。

- **直接证据**：访谈原话、观察、行为记录、问卷或业务数据。区分用户自述与实际行为，自述不能自动证明发生或因果关系。
- **公开资料**：研究、讨论、竞品评论等。检查时间、样本与人群匹配；公开活跃用户和评论者可能存在选择偏差。
- **分析推断**：基于明确证据的解释，说明推理与替代解释，不改写成用户原话。
- **待验证假设**：依据不足的判断，注明不确定性、影响与验证方式；允许未知。

证据强弱综合相关性、直接性、时效、覆盖和一致性，不凭来源数量升级。转载不是独立证据，少量访谈不能支持总体占比，不制造精确置信度。材料自述的“真实用户”“深度访谈”等属于来源声明，未经核验不背书。

证据冲突时核对时间、角色、情境与定义，必要时拆分群体或保留竞争解释，不只选支持产品设想的反馈。

## 分群与画像

以足以改变决策的差异分群，不把每个受访者各做一张画像。一人可能在不同情境呈现不同需求；行为分群可重叠，但说明归属规则。企业角色关系与用户分群属于不同维度，采购者不自动等同核心使用者。

生命周期分群定义观察窗口、活跃事件和流失标准，不把课件示意阈值复制为统一规则。金额、频率与购买动机仅在相关时使用，免费产品、内部工具及早期假设不强行填写。

按任务选择画像字段，推荐覆盖：

| 分析项 | 要回答的问题 |
| --- | --- |
| 群体边界与角色 | 谁属于此群体，谁不属于，与其他角色是什么关系？ |
| 目标与成功结果 | 要完成什么，如何判断完成？ |
| 知识与能力 | 知道什么，具备什么任务能力，何处需要支持？ |
| 在乎的因素 | 时间、成本、质量、控制感、隐私等，哪些在该情境下真正重要？ |
| 行为与替代方案 | 过去或现在具体怎么做，用什么工具，付出什么代价？ |
| 场景与触发点 | 何时何地、什么事件触发需求，频率与环境约束是什么？ |
| 痛点与障碍 | 卡在哪一步，有什么后果与证据？ |
| AI 适配因素 | 哪些环节适合辅助或自动执行，能否核验、修正和接管？ |
| 证据与验证 | 哪些已观察到，哪些是推断或假设，如何验证？ |

使用描述性群体名称，不需虚构姓名、头像、年龄或人格。可保留有来源且有助解释行为的片段。“一句话”如为研究者概括，明确标为概括；只有可定位原文才作直接引语。合成场景或“一天的故事”非必填；使用时标注推演或多样本合成，不伪装成真实个人经历。

## AI 产品的条件性分析

按相关性选择，以下不全部固化为必填字段：

- 任务熟练度、AI 经验、表达需求与准备上下文的能力；不会用模型不等同于任务能力不足。
- 对质量、时延、成本和稳定性的要求，错误后果及可接受范围。
- 如何判断可信，是否有专业知识、外部依据和时间核验。
- 输入准备、数据可得性、隐私权限、系统集成及组织审批。
- 希望保留什么控制权，自动执行到哪一步需要确认，失败如何纠错与人工接管。
- 采用、重复使用及付费的动机和阻力，区分新鲜感与持续任务价值。

“喜欢 AI”不能替代需求证据；说愿意用或付费不能直接证明采用与付费行为。优先分析当前工作流及可观察变化，不预设 AI 是最合适方案。

## 验证设计

优先验证影响用户选择或产品取舍大、证据弱的假设。简洁记录：假设 → 对应群体 → 验证方式 → 观察信号 → 修正或否定条件。

访谈围绕最近发生的具体经历、步骤、替代方案及实际代价，避免诱导、推销方案和泛泛询问“会不会用”。按目的纳入当前、潜在、未采用或流失用户等，避免只访谈支持者。样本数量依差异和研究目标确定，不承诺固定人数代表总体。

定性材料用于理解机制与发现差异；定量估计分布或验证关联时说明抽样、口径及局限。原型或任务测试观察任务能否完成、是否核验、在哪里纠错或放弃。早期阈值可提出为待确认标准，不伪装成已测指标。

更新画像保留简洁变更说明：新增证据、受影响判断、调整理由、未解决冲突。验证计划是未来工作，不写成已完成研究。
